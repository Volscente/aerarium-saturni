# Initiative

## **What**

This initiative proposes to automatise the process of retrieving ETF prices and their related history.

## **Why**

The goal is to move away from a manual input insert of the ETF prices and embrace instead a fully automated process, in order to relief the user from such a burden.

## **Success Criteria**

- The update of all the ETF prices and price history should be automatic
- The user can decide whether to update the prices of all the ETFs or just chose a specific ETF for which they want to update the prices
- The trigger should be a button for the user to press located in the page “ETF Registry”. The button should allow the user to select all ETFs (default) or just few ones. The list of available ETF is the one already present in the ETF Registry.
- Remove the possibility for the user to change the price manually in the “ETF Registry” page.
- Remove the drop down history table below each ETF entry in the “ETF Registry” page.
- User can see the price variations of the ETFs in a dedicated Timeline Chart in the “ETF Registry” page.
- The user can select an ETF and its price timeseries would appear in the Timeline Chart
- The Timeline Chart would allow also to compare the price timeseries of multiple ETFs at the same time
